Default password is streamers. Change PASSWORD_HASH in this file before you commit it anywhere. This lock is a deterrent, not real security — see the deployment note in the export panel below once you're in.

Admin

Add streamers, edit any field, rename or recolor rarity tiers. When you're done, export cards-data.js and commit it — this page never publishes changes on its own.

Rarity tiers

Rename any tier, recolor it, or add a new one. Order controls filter-button order on the public site (lowest → highest).

Streamers

Set Image URL to your own art (a link, or a path like images/nova.jpg once you've added it to the repo). Leave it blank to keep the generated placeholder.

Export

Copy this into cards-data.js in your repo, or use the download button, then commit + push.

On keeping this admin page away from visitors: GitHub Pages (free plan) publishes whatever is in your public repo to a public URL — there's no login GitHub itself enforces for you. The reliable way to keep this page private is to not deploy it at all: keep admin.html/docs or /public folder, and keep this file in /admin outside it), run it locally in your browser, and only push the exported cards-data.js. The password above just discourages casual snooping if it ever does end up reachable.
